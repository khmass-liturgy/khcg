📲 홈화면에 추가하기

📱 안드로이드 (Chrome / 삼성인터넷)
1. 브라우저 우상단 ⋮ (점 3개) 메뉴
2. "홈 화면에 추가" 선택
3. 추가 버튼 → 완료!
🍎 아이폰 (Safari)
1. 하단 공유 버튼 (⬆ 네모) 탭
2. 아래로 스크롤 → "홈 화면에 추가"
3. 추가 → 완료!
💻 컴퓨터 (Chrome / Edge)
주소창 오른쪽 설치 아이콘 (⊕ 또는 모니터 모양)을 클릭하면 바탕화면 앱으로 설치돼요.

🔥 Firebase 데이터베이스 설정

처음 설정 방법
1. Firebase 콘솔에서 새 프로젝트 만들기
2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기 (테스트 모드 선택)
3. 프로젝트 개요 ⚙ → 앱 추가 → 웹(</>) → 앱 등록
4. 표시된 firebaseConfig 객체를 복사해서 아래에 붙여넣기
